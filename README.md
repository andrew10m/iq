# Погружение

Документальный сайт о жизни океана: вертикальное погружение от поверхности до дна Марианской впадины. Глубина меняется на экране, вода темнеет, гаснут лучи света, вместо пузырьков появляются «морской снег» и живой свет глубин. 46 видов, у каждого — карточка с фактами.

## Как открыть

- **На компьютере:** скачайте репозиторий (Code → Download ZIP), распакуйте и дважды кликните по `index.html`. Интернет не нужен.
- **По ссылке, в том числе с телефона:** Settings → Pages → Branch `main`, папка `/ (root)` → Save. Через минуту сайт будет доступен по адресу вида `https://<логин>.github.io/<репозиторий>/`.

## Как управлять

- Листайте вниз — это погружение. Справа (на телефоне — вверху) показана глубина.
- Нажмите «Подробнее» или на карточку вида — откроется полная карточка. Стрелками, клавишами ← → или свайпом можно листать виды.
- «Все виды» — указатель всех 46 животных по зонам.
- Отметки глубины на шкале справа кликабельны.

## Как подписать подарок

В начале `script.js` есть блок `CONFIG`: имя и от кого. Подпись появится на обложке.

## Что где лежит

- `animals.js` — все тексты о видах: факты, размеры, глубины.
- `script.js` — порядок глав (`STORY`), зоны глубины и анимации.
- `style.css` — оформление.
- `vendor/` — GSAP и ScrollTrigger (локальная копия, чтобы всё работало без интернета).
- `fonts/` — шрифты Inter Tight и Cormorant Garamond (лицензия SIL OFL).
