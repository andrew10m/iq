# Мой Океанариум

Подарочный сайт-игра для юного эксперта по морским животным. Он здесь не посетитель, а **директор собственного океанариума**.

## Что внутри

- **Погружение** — спуск от поверхности до дна Марианской впадины. Глубина меняется на экране, вода темнеет. 46 животных на четырёх глубинах.
- **Мой океанариум** — четыре бассейна (тёплое море, холодное море, риф, глубина). Животные плавают сами, реагируют на касания, их можно кормить и давать им имена.
- **Энциклопедия** — все виды с фильтрами. Неоткрытые показаны силуэтами.
- **Экзамен аса** — 4 режима викторины, 3 уровня сложности, 7 рангов от Юнги до Легенды глубин.
- **Мечта** — секретная страница, которая открывается на ранге «Директор океанариума».

## Как открыть

Дважды кликнуть по `index.html`. Интернет и сервер не нужны.

Чтобы играть с телефона, удобнее всего включить GitHub Pages: **Settings → Pages → Branch: `main` / root**. Сайт появится по ссылке вида `https://<логин>.github.io/<репозиторий>/`.

## Как подписать подарок

Откройте `script.js` и поменяйте блок `CONFIG` в самом начале:

```js
const CONFIG = {
  name: "Миша",
  fromWho: "от старшего брата",
  finalMessage: "Собирайся: в субботу едем в Москвариум!",
  finalDate: "15 июня, 11:00",
  dreamRank: 5
};
```

Пока в полях стоят заготовки в квадратных скобках, сайт их просто не показывает.

## Как поменять животных и картинки

- Все животные, факты и вопросы «Правда или миф» лежат в `animals.js`. Там же описаны все поля.
- Картинки лежат в `images/`, по файлу на животное. Чтобы заменить рисунок фотографией, положите фото в `images/` и поменяйте поле `img` у животного. Нарисованные животные смотрят влево; если на фото животное смотрит вправо, добавьте `faces: "right"`.

## Технически

- Чистые HTML, CSS и JS, без библиотек и внешних запросов.
- Прогресс хранится в `localStorage` браузера. «Начать заново» — в настройках (шестерёнка).
- Звуки генерируются в коде (Web Audio API), выключаются кнопкой.
- Шрифт Nunito лежит в `fonts/` (лицензия SIL OFL, см. `fonts/OFL.txt`).
